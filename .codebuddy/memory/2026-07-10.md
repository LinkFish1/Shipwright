## 外观/HUD 大量 UI 翻译（用户指令：查找并翻译一长串随机化器外观/HUD 字符串，数字不翻译）
- 排查关键结论（与控制器那次不同）：
  - `COSMETIC_OPTION(...)` 标签是**纯字面量**，由 widget 在读取时**自动 Translate()**（见 CosmeticsEditor 注释 `// option strings are stored as plain literals... translates each option live` + DrawElement/UIWidgets::Combobox）。所以这一类（钥匙/BOSS钥匙各部位、Magic/Arrow/Spin/Trails/World/Navi/Ivan/NPC 各主色、HUD 颜色项、各 Group 名）**只加表即生效**。
  - 但 `SliderInt/Float` 渲染标签走 `ImGui::Text(label, *value)` **没有** Translate；`ImGui::CollapsingHeader`、`CVarCheckbox("...")` 纯字面量、`Reset` 按钮（`UIWidgets::Button(Button_Title,...)` / 直接 `UIWidgets::Button("Reset##...")`）也**未**自动翻译 → 这类既要加表又要在调用点 `Translate()` 包裹。
  - SoH 没有全局自动翻译（libultraship 里 `StringHelper::Translate` 只在显式调用处生效，无 imgui 钩子）。
