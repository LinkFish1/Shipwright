## 翻译乱码（"????"/"P???"）根因与修复（用户指令：发现很多翻译错误如????、P???，找到所有类似错误并解决）
- 用户看到的乱码是**豆腐块(tofu)**，不是表里的字面 "????" 字符串（搜 `\?{3,}` 全无匹配）。
- **根因 1（真正的乱码来源）**：翻译 VALUE 中用了 7 个**不在 `DroidSansFallback.ttf`（x64/Release 与 soh/soh/SohGui/fonts 两个都是 33275 码点）里的非 ASCII 字符，导致合并进 atlas 时渲染成 "?"：

  - `—` U+2014（破折号，48×）
  - `…` U+2026（省略号，21×）
  - `·` U+00B7（中间点，28×）
  - `→` U+2192（箭头，4×）
  - `é` U+00E9（3×）
  - 用 fontTools 比对 gChineseTable 全部 4364 条 value 的码点 vs 字体 cmap，确认这 7 个 **全部缺失**，其余 1615 个非 ASCII 字符都在字体里（即无其他乱码源）。

  - `—`→`--`、`…`→`...`、`·`→`・`(U+30FB)、`→`→`->`、`é`→`e`
